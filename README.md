# Hapakat

Laman buku audio cerita rakyat Kalimantan Tengah dalam bahasa Dayak Ngaju, Maanyan, dan Bakumpay.

## Jalankan

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`. `npm run build` menghasilkan situs statis di folder `out`.

Materi di `data/` merupakan bahan sumber. Sampul, audio, dan buku yang digunakan situs berada di `public/media/`.
